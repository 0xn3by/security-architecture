### Assets and Data Classification

This section identifies the primary business and security-relevant assets within the platform and assigns a classification based on the potential impact of unauthorized disclosure, modification, or misuse.

| Asset                                    | Classification |
| ---------------------------------------- | -------------- |
| Customer organization (tenant/workspace) | Confidential   |
| User identities and accounts             | Confidential   |
| Customer project and task data           | Confidential   |
| Uploaded files and attachments           | Restricted     |
| API keys and integration tokens          | Restricted     |

### Classification Levels

* Public – Less sensitive information approved for unrestricted disclosure.

* Internal – Information intended only for employees and platform operators.

* Confidential – Customer or business-sensitive information that must not be publicly exposed.

* Restricted – Highly sensitive information requiring the strongest level of protection due to the risk of significant security or customer impact if exposed.
